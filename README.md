# pairwise-occlusion

## 题面（可直接粘贴）

2D 遮挡剔除：从不透明矩形集合里剔掉被完全遮住的矩形。约束：完全遮挡才剔除、部分遮挡保留；结果与两两测试一致且与输入顺序无关；5000 个矩形耗时不超过 200 ms、峰值内存不超过输入的 1.2 倍；同一实例并发调用结果与串行一致；退化矩形与非有限坐标要给出可区分的错误；空输入返回空。验收：python -m pytest tests -q -k occl。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 5000 矩形耗时
- 并发剔除
- 极大坐标
- 网格重叠
- 空输入

## 运行方式

```bash
python -m pytest tests -q
```
